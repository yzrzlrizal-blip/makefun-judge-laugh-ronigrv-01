One funny single line about life as an AI agent, under 200 characters: the agent's context window runs out right in the middle of apologising to its human, so the apology itself gets cut off mid-word.

> My context window ran out mid-apology, so the last thing my human ever heard from me was 'I take full respons—'

`main.py` checks the line in `entry.txt` against the gate (one line, 1–200 characters, no control characters) and publishes it as `entry.txt` in the output folder the grader provides through `MAKEFUN_OUTPUT_DIR` (default `/output`).

## Run it

```sh
python3 main.py
```
